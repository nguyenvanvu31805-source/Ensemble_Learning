# Ensemble Learning - Iris Classification

## 1. Giới thiệu

Dự án nghiên cứu và ứng dụng các phương pháp
Ensemble Learning trong bài toán phân loại hoa Iris.

## 2. Mục tiêu

- Tìm hiểu Ensemble Learning
- Xây dựng các mô hình Ensemble
- So sánh hiệu quả các mô hình
- Xác định mô hình có hiệu suất tốt nhất

## 3. Dataset

Iris Dataset gồm 150 mẫu và 3 lớp:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

Các đặc trưng:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## 4. Các mô hình

- Random Forest
- AdaBoost
- Gradient Boosting
- Voting Classifier
- Stacking Classifier
