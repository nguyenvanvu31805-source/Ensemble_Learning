# Training

Thu muc nay ghi chu quy trinh huan luyen cac model Ensemble cho bai toan Iris.

Các model duoc huan luyen la Random Forest, AdaBoost, Gradient Boosting, Voting
va Stacking. File train chinh la `app/train.py` va co the chay bang:

```bash
python -m app.train
```

Bang metric luu tai `results/comparison.csv`. Model va scaler duoc tao tai
`models/` va co the sinh lai bat ky luc nao.
